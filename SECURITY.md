# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project,
please report it privately by emailing: contact@meetpavan.com

Do not open a public GitHub issue for security vulnerabilities.

I will acknowledge your report within 48 hours and aim to
release a fix within 7 days for critical issues.

## Supported Versions

This is a portfolio project. The latest version on main
is the only supported version.
